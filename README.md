# KARTUN05

Website profil Karang Taruna RT 05 RW 12. Dibangun dengan Next.js, React, Vinext, dan Tailwind CSS.

## Isi website

- Profil KARTUN05
- Statistik anggota dan kegiatan
- Empat bidang program
- Jejak kegiatan terlaksana
- Agenda 17 Agustus 2026 dan doorprize
- Pendaftaran melalui WhatsApp
- Dokumentasi Instagram

## Menjalankan lokal

```bash
npm install
npm run dev
```

## Validasi

```bash
npm run lint
npm run build
```

Foto dan video kegiatan dapat ditambahkan setelah ekspor data Instagram tersedia.
